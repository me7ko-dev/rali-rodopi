# Рали Родопи

3D рали в браузъра. Можеш да се състезаваш онлайн с други хора в реално време, сам срещу ботове или в шампионат по шестте писти. Има профили, класации и гараж, а също нитро и дрифт. Играе се на компютър и на телефон.

**Играй:** https://me7ko-dev.github.io/rali-rodopi/

Играта е и в Метко Стор: https://me7ko-dev.github.io/

## Начини на игра

- **Онлайн.** Профилът е само име и парола, без имейл и без чат.
  - „Бързо състезание“ събира до 8 души на случайна писта. Ако за 15 секунди не дойдат достатъчно хора, местата се допълват с ботове.
  - „Стая за приятели“ дава 6-знаков код. Приятелите влизат с него, а домакинът избира пистата, броя обиколки и кога да тръгнат.
  - Сървърът сам проверява всяко състезание: реда на отсечките, скоростта на колата и най-бързата възможна обиколка. Невъзможните резултати не влизат в класацията.
- **Сам с ботове.** Три обиколки срещу петима съперници, като тръгваш последен.
- **Шампионат.** Шестте писти подред с точки: 10, 8, 6, 5, 4, 3, плюс 2 за финал.
- **Гараж.** Точките от състезанията отключват бои, номера, спойлери и следи от нитро. Те променят само вида на колата, не и скоростта.
- **Класации.** Най-добра обиколка за всяка писта и точки за седмицата. Твоят ред се показва отделно.

Ако сървърът не отговаря, играта продължава без него. Ако връзката падне по време на онлайн състезание, играта опитва да се свърже отново. Ако не успее, другите коли стават ботове и състезанието продължава.

## Управление

| Клавиатура | Действие |
|---|---|
| ↑ / W | газ |
| ↓ / S | спирачка |
| ← → / A D | завой |
| Space | дрифт (ръчна) |
| Shift | нитро |
| R | връщане на пистата |
| P / Esc | пауза |
| Enter | старт от менюто |

**На телефон** колата сама дава газ. Обърни телефона хоризонтално.
- Вляво са големите бутони ◀ ▶.
- Вдясно са „N₂O“, „Дрифт“, „Стоп“ и ↺ (връщане на пистата).

Ако телефонът не смогва, качеството на картината намалява само. Можеш да го избереш и ръчно от „Качество“ в менюто.

## Пускане на компютъра

Самата игра е от статични файлове, без сглобяване ([three.js](https://threejs.org/) идва от CDN):

```
git clone https://github.com/me7ko-dev/rali-rodopi.git
cd rali-rodopi
npm install          # само за тестовете (playwright-core)
npm run serve        # после отвори http://127.0.0.1:8000/
```

Адресът на онлайн сървъра е на едно място, в `js/config.js`. С `?api=off` играта върви без сървър. С `?api=http://localhost:8798` ползва локален сървър.

## Онлайн сървърът (`server/`)

Сървърът е Cloudflare Worker с Durable Objects и база D1:
- `Lobby` събира хората и пази кодовете на стаите.
- `RaceRoom` е едно състезание: WebSocket, обратно броене, позиции 15 пъти в секунда, ботове, проверка на резултата и класиране.

Физиката, обиколките и проверката са общи с играта (`js/core/`), затова сървърът брои точно както браузърът.

```
cd server
npm install
npm run schema:local   # веднъж, за локалната база
npm run dev            # http://localhost:8798
```

## Тестове

```
npm test                         # ядрото без браузър: писти, физика, обиколки, съдия, гараж
npm run smoke                    # Chrome на компютър и телефон (софтуерен WebGL)
node test/online.mjs [адрес]     # двама роботи през WebSocket: стая, състезание, класация, отхвърлена измама
node test/online-ui.mjs          # браузърът срещу робот в стая с код
```

Тестовете с браузър ползват инсталирания Google Chrome, не свалят свой.

Папки:
- `index.html`, `js/` (игра, коли, писти, мрежа, гараж), `js/core/` (общото с сървъра), `css/`
- `assets/` (3D модели), `icons/`, `server/`, `test/`
