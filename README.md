# Рали Родопи

3D рали в браузъра: шест коли, три писти, три обиколки. Тръгваш последен и трябва да изпревариш петима съперници. Има нитро, дрифт и най-добра обиколка за всяка писта.

**Играй:** https://me7ko-dev.github.io/rali-rodopi/

Играта е и в Метко Стор: https://me7ko-dev.github.io/

## Писти

- **Язовир Доспат**: утро, плавни завои
- **Велинград**: залез, техничен
- **Сърница**: привечер, дълъг и бърз

## Управление

| Клавиатура | Действие |
|---|---|
| ↑ / W | газ |
| ↓ / S | спирачка |
| ← → / A D | завой |
| Space | дрифт (ръчна) |
| Shift | нитро |
| R | връщане на пистата |
| P / Esc | пауза |
| Enter | старт от менюто |

На телефон колата върви сама. Отдолу има бутони ◀ ▶, „N₂O“, „Дрифт“ и „Стоп“. Най-добре се играе с хоризонтален екран.

## Пускане на компютъра

Няма сглобяване, само статични файлове ([three.js](https://threejs.org/) от CDN):

```
git clone https://github.com/me7ko-dev/rali-rodopi.git
cd rali-rodopi
python -m http.server 8000
```

После отвори http://localhost:8000/.

Папки: `index.html`, `js/` (игра, коли, писти, звук), `css/`, `assets/` (3D модели), `icons/`.
